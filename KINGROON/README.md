# KINGROON Filament Profiles

This folder contains ready-to-import filament profiles for KINGROON filaments.

## Source

Original profiles downloaded from: [KINGROON Google Drive](https://drive.google.com/drive/folders/1Mhjo4AZax7hLg0XIYlN9jlGMfXtFdSOA)

## How to Import

See the [detailed import guide](../docs/how-to-import.md#method-1-import-bbsflmt-bundle-files-recommended) for step-by-step instructions with screenshots.

## Available Profiles

- **KINGROON ABS Basic.bbsflmt** - ABS filament profile
- **KINGROON PETG Basic.bbsflmt** - Basic PETG profile
- **KINGROON PETG HS.bbsflmt** - High Speed PETG profile
- **KINGROON PETG-CF Basic.bbsflmt** - Carbon Fiber reinforced PETG
- **KINGROON PLA + Basic.bbsflmt** - Enhanced PLA+ profile
- **KINGROON PLA Basic.bbsflmt** - Standard PLA profile
- **KINGROON PLA Matte.bbsflmt** - Matte finish PLA
- **KINGROON PLA Pro.bbsflmt** - Professional grade PLA
- **KINGROON PLA Silk.bbsflmt** - Silk/glossy finish PLA
- **KINGROON TPU 95A.bbsflmt** - Flexible TPU filament

## Notes

All profiles include settings for multiple Bambu Lab printers:
- A1 / A1 mini
- H2D / H2S
- P1P / P1S / P2S
- X1 / X1 Carbon
