# BambuStudio_CustomFilaments

Repository with filament profiles for [Bambu Studio](https://bambulab.com/en/download/studio)

## Supported Filament Brands

### [KINGROON](KINGROON/)
Ready-to-import `.bbsflmt` profile bundles for KINGROON filaments.

**Available profiles:**
- ABS Basic
- PETG Basic, PETG HS, PETG-CF Basic
- PLA Basic, PLA+, PLA Matte, PLA Pro, PLA Silk
- TPU 95A

[📖 See KINGROON README for import instructions](KINGROON/README.md)

### [eSun](eSun/)
JSON profile files organized by printer model.

⚠️ **Note:** These are partial profile definitions that require manual integration or conversion. Ready-to-import `.bbsflmt` files are available in the `eSun/Filament bundle/` subfolder.

**Available filament types:**
- PLA variants (Basic, +, Silk, Matte, CF, LW, etc.)
- PETG variants (Basic, HS, CF, Matte, ESD)
- Engineering materials (ABS, ASA, PA, PC)
- Flexible materials (TPU, TPE, PEBA)

[📖 See eSun README for usage instructions](eSun/README.md)
